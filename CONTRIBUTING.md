# Contributing to Web Intel

Thank you for your interest in contributing. This project is maintained by [kmfazle](https://kmfazle.dev).

## Getting started

1. Fork the repository and clone your fork.
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Open http://localhost:5173 and test your changes.

## Development commands

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Local development server |
| `npm run build`   | Production build         |
| `npm run lint`    | ESLint                   |
| `npm run format`  | Prettier                 |
| `npm run preview` | Preview production build |

## Pull requests

- Keep changes focused and describe what problem they solve.
- Run `npm run lint` and `npm run build` before opening a PR.
- Add screenshots for UI changes when possible.

## Reporting issues

Use [GitHub Issues](https://github.com/km-fazle/web-intel/issues) and include:

- Steps to reproduce
- Expected vs actual behavior
- Browser or deployment environment (Vercel, Cloudflare, local)

## Code of conduct

Be respectful and constructive. Security-sensitive findings should be reported responsibly (see [SECURITY.md](./SECURITY.md)).
