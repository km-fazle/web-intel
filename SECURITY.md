# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email or contact the maintainer via [kmfazle.dev](https://kmfazle.dev) with:

- A description of the issue
- Steps to reproduce
- Impact assessment if known

You will receive a response as soon as possible.

## Scope

Web Intel performs passive OSINT lookups against user-supplied domains. If you find SSRF, injection, or data-exposure issues in server functions, please report them promptly.
